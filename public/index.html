Supabase Database Integration

Quick connection guide for your second-year IT project

1

Create Supabase Project & Run SQL

Go to Supabase.com, create a project, and run the SQL script in supabase/schema.sql inside the Supabase SQL Editor.

supabase/schema.sql
2

Retrieve Project Credentials

In Supabase Dashboard, open Project Settings → API and copy your:

  • Project URL (e.g. https://xyzcompany.supabase.co)
  • service_role Secret (recommended for backend server) or anon Public Key
3

Update server/.env

Paste the credentials in server/.env file:

PORT=3000
SUPABASE_URL=https://your-project-id.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your-actual-supabase-key-here
4

Restart Express Server

Restart the server with npm start to connect and manage live records.
